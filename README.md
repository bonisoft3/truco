# Truco

Truco is a Brazilian card-game app: a small, authored world rather than a
generic game skin. It brings Paulista and Mineiro rules, 2v2 multiplayer
online matches with networked shouts, the table language, and the rhythm of
regional play into one offline-first experience.

It is a reference app for the cultural and local character that an independent
author can carry all the way into a working product.
