# Truco

Truco is a Brazilian card-game app: a small, authored world rather than a
generic game skin. Its local table offers regional variants and bots; the
[[docs/online-hybrid|online table]] offers authoritative 1×1, 2×2 and 2×2×2 matches with the supported regional variants, private hands, recoverable commands, and a lobby with online/offline
visibility and direct player challenges.

It is a reference app for the cultural and local character that an independent
author can carry all the way into a working product.

The [[brief.md|brief]] defines the variants, table conventions, and play modes.

[[docs/index|Documentation]] covers the shared hybrid machines, online implementation and
hatch-free table presentation.
